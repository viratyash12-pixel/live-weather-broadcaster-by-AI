Live Weather CLI

A simple command-line tool that fetches real-time weather for any city or place — no API key required. Powered entirely by the free Open-Meteo API.

What it does
Asks you to type in a city or place name.
Looks up its coordinates using Open-Meteo's geocoding API.
Fetches current weather conditions for those coordinates.
Prints a clean summary: condition, temperature (with "feels like"), humidity, and wind speed.
